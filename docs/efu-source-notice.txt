The launcher wrapper invokes EFU as a separate, locally patched source-built executable in silent
normal-game-launch mode. It does not merge EFU's hook implementation into the
Vulkan observer. EFU implements its own no-dither behavior; it does not implement
XeSS, FSR frame generation replacement, or the Vulkan-to-XeFG bridge.
The preview also modifies the local OneChannel launcher-source check only when
its original result is error 10100. It does not replace account login or anti-cheat.
The wrapper admits only the reviewed game/UnityPlayer/OneChannelLC file hashes.

Starting EFU, loading its DLL, or observing exit code zero does not verify that
its runtime effect succeeded. This release build still requires its own in-game acceptance test.

Local launcher delta: patches/efu-launcher-options.patch; complete source is included.
Reproduction entry: scripts/build-efu-launcher-options.ps1
The source snapshot includes upstream files and the local modifications.
The corresponding derived source includes its patch and original-source provenance.
The CameraPitch detour uses private static MinHook v1.3.4 at commit
c3fcafdc10146beb5919319d0683e44e3c30d537. The resolver registers its own native worker with IL2CPP before metadata lookup,
releases that registration on the same thread before MinHook/hotkey work, and
retains the upstream initial module settle delay. The OneChannel compatibility code
retains the upstream hook engine. Runtime diagnostics write only to the fixed
new-session EFU_RUNTIME_LOG path set by the protected launch manager.
MinHook source: https://github.com/TsudaKageyu/minhook/tree/c3fcafdc10146beb5919319d0683e44e3c30d537
