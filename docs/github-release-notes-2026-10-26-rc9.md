# I卡终末地xess超分+帧生成 · v0.1.0

Windows x64 精简发行版。包含已验收的角色菜单冻结修复，以及新的紧凑启动器。

## 本版更新

- 启动器改为单实例：同一 Windows 用户、同一会话中再次启动，会唤出现有窗口，不再打开多个启动器；收起到托盘后同样有效。
- 紧凑布局，倍率与场景阈值并排，减少留白。保留2×／3×／4×、免虚化、自定义基础帧率及可选诊断。
- 新的程序、任务栏和托盘图标，并加入高 DPI 清晰显示支持。
- 渲染模组与 Claude 已验收的角色菜单修复版相同，没有在本次 UI 更新中改动超分或插帧实现。

## 技术路径

游戏继续使用 Vulkan 渲染。XeSS 超分在 Vulkan 内替换 FSR 超分核心；帧生成经同一显卡的共享资源交给 D3D12／DXGI 的 XeSS FG 输出。游戏并非整体切换到 DX12。

## 使用

1. 下载 `*-win64.zip` 并完整解压。先退出游戏与相关启动器，运行 `Verify.cmd` → `Install.cmd` → `Launch.cmd`。
2. 首次选择游戏目录。游戏内选择“画质提升：AMD FSR3”和放大档位，由 XeSS 接管；开启“FSR3 Frame Generation”即启用 XeSS 插帧。
3. 倍率等启动器设置需重新启动游戏生效。示例：选3×、把30帧档映射为40，在游戏内选择30帧，目标约120显示帧。

## 环境与验证范围

推荐 Windows 11 x64、兼容 XeSS FG 的 Intel Arc 独显或 Core Ultra 核显、Intel 驱动32.0.101.7029或更新、PowerShell 7 x64，以及VC++ x64运行库14.40.33810或更新。主要实机设备是Arc B390，其他型号尚未逐一验证。游戏版本必须通过本包适配的模块校验。

本次通过41项已注册回归（含单实例多进程测试）与启动器275项自检；在桌面验证了托盘收起、二次启动唤回、已有倍率／限帧设置保留。模组DLL与Claude已验收版本哈希相同；没有为UI更新重复要求游戏短测。

默认没有运行监控、状态面板或运行日志。需要排错时，诊断模式只对显式勾选的一次启动生效。
