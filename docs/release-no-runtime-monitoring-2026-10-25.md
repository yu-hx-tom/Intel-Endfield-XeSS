# 精简发行版：默认无运行监控

rc8起按用户最新要求取消运行监控，取代rc5～rc7的实时状态约定。

## 默认启动

- 没有SR／FG实时状态面板，不显示帧率、计数、恢复进度或心跳。
- 不建立、读写运行状态共享内存；发行源码已移除该通道实现及原始帧率采样器。
- 不创建Sessions、运行日志或保留策略文件，不启动日志写线程。
- 不分配测量窗口、快照、直方图；不启用CPU耗时采样或补帧输出统计。
- 启动器只处理设置、路径校验和启动结果。启动／路径助手结束后取消其UI定时器，不持续轮询游戏。
- 用户偏好文件、安装收据及游戏路径配置正常保留。

## 显式诊断

只有用户勾选“诊断模式”后，该次启动才创建诊断会话并启用日志、测量窗口及CPU耗时统计。选择在提交启动请求时消费，下次仍关闭。诊断也不恢复运行状态共享内存或实时面板。

录制器是独立工具，默认未启用诊断时仍可读取现有PMDP和硬件传感器；模组测量源应记为不可用，不应因此判录制失败。发行包不自动启动录制器、PresentMon或RTSS。

历史会话不自动删除；诊断局清理仍按原规则只读预览，删除需要另外明确授权。

## 功能逻辑

超分与补帧需要的输入匹配、当前帧状态、图像布局、资源生命周期、SDK返回值与同步仍是渲染必需数据。启动页禁止插帧仍检查游戏是否进入正式游玩；不会因为取消监控而取消这个判断。限帧映射、倍率、免虚化设置及正常错误提示仍保留。

功能上的帧调度、XeLL、Fence等待和故障回退没有改成依赖诊断。默认模式不宣称或推测XeSS当前成功帧数；需要排错时由用户显式生成诊断日志。
